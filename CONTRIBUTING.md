# Contributing

Read [ARCHITECTURE.md](ARCHITECTURE.md) before changing rules or native boundaries.
Use Node 22.12 or later and the stable Rust MSVC toolchain on Windows. Run `npm ci`.

Use feature branches and reviewable pull requests. Run `npm run lint`,
`npm run typecheck`, `npm test`, `npm run test:contracts`, and `npm run test:e2e`.
For Rust changes run `npm run test:native`, `cargo fmt --check`, and strict Clippy
for the affected crate. Install Chromium with `npx playwright install chromium`.

The canonical `rules/european-v1.json` is generated by
`npm run generate:catalog`. Existing rules versions are immutable once released.
A rule change needs a new version and matching native/TypeScript fixtures.

Gameplay must work without network access, accounts, paid APIs, or development
tools. Do not add telemetry, remote fonts/assets, runtime model calls, or payments.
Prompts, responses, source, transcripts, tool arguments, paths, and raw hook JSON
must never become integration events or diagnostic logs.

Keep randomness and financial authority in platform services. UI animation is
presentation only. Preserve request identities and ledger records across retries,
crashes, wallet resets, and history clearing. Unknown Agent evidence refunds its
stake; never replace missing evidence with a random outcome.

UI design and implementation use GPT Astra as specified by the architecture;
verify playable interactions, keyboard access, reduced motion, and screenshots
at compact and standard sizes. Do not enable optional integrations solely because
unit tests pass: record actual supported provider and native lifecycle checks.
