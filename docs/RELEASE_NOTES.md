# Commit Casino 0.1.0

Initial offline Windows x64 and browser editions: all 157 European roulette bets,
transactional local wallet, recovery, history/statistics, keyboard picker,
procedural wheel/audio, reduced motion, and optional passive Claude integration.
Agent predictions use conservative registered verification evidence and refund
uncertain outcomes. No real money, accounts, paid runtime services, or telemetry.

Windows installer includes WebView2 for first-time offline setup. It is unsigned;
unknown-publisher prompts are expected. Browser files need HTTPS or localhost
for service-worker installation. Wallets are local to each installation/origin.

Artifacts: Windows installer, standalone helper, static browser ZIP, dependency
license ZIP, and SHA-256 checksums. See IMPLEMENTATION.md for the exact tested
provider/runner versions and the distinction between actual lifecycle tests and
simulated evidence fixtures. No macOS/Linux installation claim is made.
